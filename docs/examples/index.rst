Examples
========

The examples are notebooks in the ``examples`` directory of the repository, and are
executed by the test suite. :doc:`../user-guide/index` describes how the parts fit
together.

**Peak factor models** (:doc:`example-01`)
    The response spectrum of one source-theory Fourier spectrum computed with each
    peak calculator, including those that depend on the region, magnitude and
    distance.

**Compatible Fourier spectra** (:doc:`example-02`)
    The Fourier amplitude spectra that match a target response spectrum for each
    peak calculator, and the attenuation that they imply.
